Growth & Depreciation

Model population growth, increasing prices and depreciation as repeated percentage change.

↗
Learn → Explore → Practice → Challenge
Core idea

Repeated percentage change

Growth

A quantity increases by the same percentage of its current value each period.

Pₜ = P(1 + R/100)ᵀ

Increase

The total increase is final value minus initial value.

Increase = Pₜ − P

Depreciation

A value decreases by a percentage of its current value each period.

Vₜ = V₀(1 − R/100)ᵀ

Different yearly rates

Use one growth/depreciation factor for each year.

Pₜ=P(1+R₁/100)(1+R₂/100)…

Migration / deaths

Apply percentage growth, then adjust for migration/death where the problem states it.
