## Structure
- `index.html` — master dashboard
- `styles.css` / `app.js` — dashboard styling and behavior
- `modules/` — all chapter labs
- `modules/shared/lab.css` — shared styling for the newer labs

## Deploy to GitHub Pages
Upload the **contents of this folder** to the root of your existing repository.
Then go to Settings → Pages → Deploy from a branch → `main` → `/ (root)`.

No build tools, npm, backend or database are required.
