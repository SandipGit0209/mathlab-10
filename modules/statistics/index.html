Class 10 foundation

Read a continuous frequency table first

Class interval

Examples: 10–20, 20–30, 30–40. In a continuous series, one class ends exactly where the next begins.

Frequency (f)

The number of observations in a class interval.

N = Σf

Mid-value (m)

Used to find the mean of a grouped series.

m = (lower + upper) / 2

Cumulative frequency (cf)

Running total of frequencies. It helps locate Q₁, median and Q₃ classes.

Mean

x̄ = Σfm / N

Alternative method: choose assumed mean A, then d = m − A.

x̄ = A + Σfd / N

Median

Md = L + [(N/2 − cf) / f] × h

Mode

Mo = L + [(f₁−f₀)/(2f₁−f₀−f₂)] × h

First quartile

Q₁ = L + [(N/4 − cf) / f] × h

Third quartile

Q₃ = L + [(3N/4 − cf) / f] × h
Most important exam habit: before using median, Q₁ or Q₃ formula, first make the less-than cumulative frequency column and identify the class containing the required position.

Start with the modal class

Substitution
Remember: the modal class is the class interval with the highest frequency. Here, f₁ = frequency of modal class, f₀ = frequency before it, and f₂ = frequency after it.
